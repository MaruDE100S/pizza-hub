# 🍕 PizzaHub

Welcome to **PizzaHub**! This is a school project showcasing a fully functional pizza ordering website. The platform is designed to handle the entire pizza delivery lifecycle, from customer orders to administration and delivery management.

## ✨ Features

- **Authentication System:** Secure login & signup for users.
- **Dynamic Cart & Order System:** Browse pizzas, add to cart, and place orders seamlessly.
- **User Profiles:** Manage personal information and view order history.
- **Admin Dashboard:** Comprehensive control over the menu, orders, and user management.
- **Delivery Management:** Dedicated panel for delivery personnel to track and update order statuses.
- **Consistent UI:** Universal header and footer across all pages for easy navigation.

## 👥 User Roles & Permissions

The platform supports four distinct user roles, each with specific capabilities:

### 1. 🌐 Guest (Unauthenticated User)
- Can browse the pizza menu
- Can place an order (with guest details)

### 2. 👤 Customer (Authenticated User)
- Can browse and order pizzas
- Can view past and current orders
- Can access and manage their user profile

### 3. 🛡️ Administrator
- Can manage the menu (add, update, delete pizzas)
- Can view all orders across the system
- Can update the status of any order
- Can view a list of all registered users

### 4. 🛵 Delivery Person
- Can view orders specifically assigned to them
- Can update the delivery status of assigned orders

## 🛠️ Technology Stack

This project is built using a robust web development stack:

- **Frontend:** HTML5, CSS3, Vanilla JavaScript, AJAX, Bootstrap 5
- **Backend:** PHP
- **Database:** MySQL
